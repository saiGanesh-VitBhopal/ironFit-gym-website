# 🏋️‍♂️ Gym Website (React)

A modern, responsive **Gym & Fitness website** built using **React**.  
This project focuses on component-based architecture, clean UI structure, and reusable components — ideal for beginners learning React fundamentals.

---

##  Features

- Responsive gym landing page
- Clean and modern UI
- Component-based structure
- Reusable React components
- Easy to customize and extend

---

##  Tech Stack

- **React** (with Vite)
- **JavaScript (ES6)**
- **CSS**
- **HTML5**

##  Components Overview

- **Navbar** – Navigation bar with gym branding and links
- **Hero** – Landing section with gym tagline and call-to-action
- **Programs** – Displays available fitness programs
- **Trainers** – Showcases gym trainers
- **Contact** – Contact form / gym contact details
- **Footer** – Footer with copyright and links
